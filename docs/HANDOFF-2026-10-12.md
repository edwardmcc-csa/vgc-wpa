## Decisions taken (by the PO)

1. **Reg M-A and Reg M-B are two formats** (`DEFINITIONS` §15, rev 7). Models, calibration and evaluation per format; splits inside each format. Data is unequal: 84,738 M-A battles vs 4,167 M-B (~5%); state sample sizes with every M-B number.
2. No licence issues with any dependency or dataset.
3. **Order of work:** close Week 3 (done) → M3 and M4 (parallel only if two engineers) → specified-team simulation harness → M4b → M5 → M7 → scope the team-building layer (M8).
4. **No strict monotonicity test.** "Removing an opposing Pokémon never lowers your WP" is false in real play (a weak active left alive; a running Tailwind; own-side sacrifices). Use a reported trend plus expert-claim cases. `DEFINITIONS` line 122 (set win probability monotone in game win probability) is a different, valid property.
5. **Timers must be in the state** (Tailwind, Light Screen, Reflect, Aurora Veil, Trick Room, Encore, Disable, weather, terrain, and others). Random timers with a known distribution given an observable count are **features**. Verified in the pinned `champions` mod: sleep is `sample([2,3,3])` (turn 1 always asleep, 1/3 wake turn 2, guaranteed wake turn 3); freeze thaws 1/4 per turn, 3-attempt cap; full paralysis 1/8; Tailwind 4 (6 with Persistent); Light Screen 5 (8 with Light Clay); Trick Room 5 (7 with Persistent); Encore 3 (+1 if target already moved; mod overrides its start); Disable 5 (−1 if target hasn't moved). **Generate the table from the Showdown source; never hand-write it. Compute turns remaining from the start turn, never from the end event (leakage).**
6. Adding timers means another re-parse (~103 min). Bundle every feature the learned model needs into **one** second re-parse, decided by the PO after the Week 4 report.

## Findings that overrode earlier assumptions

- **Tera is disabled in this format** (0 events in 88,905 battles; Mega Evolution works). `DEFINITIONS` §12.2 and §12.3 still describe Tera as hidden information: stale, PO has not approved the edit.
- **Nature** is shown on every Reg M-B sheet and no Reg M-A sheet; EVs, IVs, Tera type never shown.
- **HP is percentage-only** in all 88,905 battles (`docs/OBSERVATIONS.md`): every damage observation is an interval. Exact HP pins come only from the specified-team simulation harness.
- **Seed control is not exposed** by the pinned Showdown (`docs/DETERMINISM.md`). The 20-fixture corpus is the reproducibility mechanism; do not regenerate it.
- Parsed output in vgc-bench's format is ~80x larger than the logs (`docs/DATA-FOOTPRINT.md`); our own `wpa_states` format is 5.3GB.
